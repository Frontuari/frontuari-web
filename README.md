Repositorio oficial del frontend para la presencia web corporativa de **Frontuari, C.A.**, empresa especializada en soluciones de software corporativo, ingeniería de datos y administración de infraestructura.

## 🎯 Objetivo del Proyecto

El objetivo principal de este proyecto es proporcionar una interfaz web moderna, altamente responsiva (Mobile-First) y accesible que comunique eficazmente el portafolio de servicios tecnológicos de Frontuari (implementación de ERP iDempiere, Inteligencia de Negocios, Desarrollo Móvil y Administración de Servidores Linux). 

La arquitectura está orientada al rendimiento, la escalabilidad y la facilidad de mantenimiento para futuras integraciones.

## 🛠️ Stack Tecnológico

Este proyecto está construido utilizando estándares modernos de desarrollo web:

- **Framework:** [Next.js](https://nextjs.org/) (App Router)
- **Biblioteca UI:** [React](https://reactjs.org/)
- **Lenguaje:** [TypeScript](https://www.typescriptlang.org/) para un tipado estricto y código más seguro.
- **Estilos:** [Tailwind CSS (v3)](https://tailwindcss.com/) configurado estrictamente bajo el manual de identidad corporativa de la marca.
- **Iconografía:** [Lucide React](https://lucide.dev/)
- **Entorno de ejecución validado:** Node.js sobre distribuciones Linux (ej. Debian).

*Nota para colaboradores:* El proyecto utiliza módulos ECMAScript (`"type": "module"` en el `package.json`), por lo que los archivos de configuración de Tailwind y PostCSS utilizan la extensión `.cjs`.

## ⚙️ Requisitos Previos

Antes de clonar el proyecto, asegúrate de tener instalado en tu sistema local:

- [Node.js](https://nodejs.org/es/) (v18.x o superior)
- npm (Gestor de paquetes integrado con Node.js)
- Git
